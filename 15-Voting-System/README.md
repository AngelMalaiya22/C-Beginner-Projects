# Voting System

## Overview

A simple C program that simulates a basic voting system. Users can cast votes for predefined candidates, and the program counts the votes and announces the winner after voting ends.

## Features

* Vote for predefined candidates
* Automatic vote counting
* Displays election results
* Announces the winner
* Beginner-friendly implementation

## Technologies Used

* C

## How to Run

1. Compile the program using a C compiler.
2. Run the executable.
3. Enter a candidate's name to cast a vote.
4. Type **result** to end voting and view the final results.
