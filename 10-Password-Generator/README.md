# Password Generator

## Overview

A simple C program that generates a random password based on the user-specified length. The generated password contains uppercase letters, lowercase letters, digits, and special characters.

## Features

* Generate passwords of any length
* Uses uppercase and lowercase letters
* Includes numbers and special characters
* Random password generation
* Beginner-friendly implementation

## Technologies Used

* C

## How to Run

1. Compile the program using a C compiler.
2. Run the executable.
3. Enter the desired password length.
4. View the generated password.
