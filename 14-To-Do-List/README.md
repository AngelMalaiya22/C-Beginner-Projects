# To-Do List

## Overview

A simple C program that helps users manage their daily tasks. Users can add new tasks, view all existing tasks, and remove completed tasks through a menu-driven interface.

## Features

* Add new tasks
* View all tasks
* Remove tasks
* Menu-driven interface
* Beginner-friendly implementation

## Technologies Used

* C

## How to Run

1. Compile the program using a C compiler.
2. Run the executable.
3. Choose an option from the menu.
4. Add, view, or remove tasks as needed.
