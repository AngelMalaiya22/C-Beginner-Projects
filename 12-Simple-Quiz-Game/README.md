# Simple Quiz Game

## Overview

A simple C program that presents the user with multiple general knowledge questions, checks each answer, and displays the final score at the end of the quiz.

## Features

* Five quiz questions
* Instant feedback for each answer
* Score tracking
* Displays final score
* Beginner-friendly implementation

## Technologies Used

* C

## How to Run

1. Compile the program using a C compiler.
2. Run the executable.
3. Answer each question as prompted.
4. View your final score after completing the quiz.
