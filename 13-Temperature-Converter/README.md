# Temperature Converter

## Overview

A simple C program that converts temperatures between Celsius and Fahrenheit. Users can choose the conversion type, enter a temperature, and instantly view the converted result.

## Features

* Convert Celsius to Fahrenheit
* Convert Fahrenheit to Celsius
* Menu-driven interface
* Displays results with two decimal places
* Beginner-friendly implementation

## Technologies Used

* C

## How to Run

1. Compile the program using a C compiler.
2. Run the executable.
3. Select the conversion type.
4. Enter the temperature value to view the converted result.
