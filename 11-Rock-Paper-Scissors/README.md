# Rock Paper Scissors

## Overview

A simple C implementation of the classic Rock Paper Scissors game where the user competes against the computer. The computer makes a random choice, and the winner is determined based on the game rules.

## Features

* Play against the computer
* Random computer choices
* Win, lose, or tie detection
* Play multiple rounds
* Beginner-friendly implementation

## Technologies Used

* C

## How to Run

1. Compile the program using a C compiler.
2. Run the executable.
3. Choose Rock, Paper, or Scissors.
4. View the result and play again if desired.
