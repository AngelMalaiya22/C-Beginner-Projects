# Expense Tracker

## Overview

A simple C program that helps users record and manage daily expenses. Users can add expenses, view all recorded expenses, and calculate the total amount spent through an interactive menu.

## Features

* Add new expenses
* View all expenses
* Calculate total expenses
* Menu-driven interface
* Beginner-friendly implementation

## Technologies Used

* C

## How to Run

1. Compile the program using a C compiler.
2. Run the executable.
3. Choose an option from the menu.
4. Add and manage your expenses.
